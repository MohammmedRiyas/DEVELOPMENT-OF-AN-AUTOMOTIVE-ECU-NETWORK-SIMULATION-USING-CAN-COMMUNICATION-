# DEVELOPMENT OF AN AUTOMOTIVE ECU NETWORK SIMULATION USING CAN COMMUNICATION 
 This project focuses on simulating an automotive electronic control unit (ECU) network using CAN (Controller Area Network) communication. It combines a Python-based vehicle dashboard with two ESP32 nodes and MCP2515 CAN controllers to demonstrate how vehicle data can be transmitted, received, and monitored over a CAN bus.  The dashboard displays key vehicle parameters such as speed, RPM, engine temperature, battery voltage, fuel level, and pollution levels. Users can interact with the simulation through sliders and controls for ignition, gear selection, seat belt status, and SOS alerts.  In hardware mode, vehicle parameters are sent from the PC to a transmitter node, transferred over the CAN bus, and received by a second ESP32 node. The received data is then sent back to the dashboard for real-time visualization. The system also includes CAN communication monitoring, a 16×2 LCD interface, and SOS alert functionality.  The project is developed using **Python, PySide6, ESP32, MCP2515, and CAN communication**, providing a practical way to understand automotive networking, ECU communication, and embedded system integration.  **Key Features** - Interactive automotive dashboard with live vehicle parameters - CAN communication using two ESP32 nodes and MCP2515 modules - Separate simulation and hardware operating modes - Real-time CAN frame monitoring and communication status - Vehicle warnings and SOS alert functionality - 16×2 LCD display support - Modular Python application built with PySide6  This project is intended for learning and demonstration purposes, showing how automotive network communication can be simulated and tested without requiring a complete vehicle ECU system.
